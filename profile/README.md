YAKBD is an open-source keyboard layout designer. A layout lives in one open file, [`.kbl.json`](https://yakbd.github.io/spec/),
and YAKBD builds it into native, installable layouts and converts existing layouts from their formats.

| platform | state |
|---|---|
| Windows, macOS, Linux | today |
| Android, iOS, ChromeOS, Keyman | planned |

| repository | what it is |
|---|---|
| [`yakbd-cli`](https://github.com/yakbd/yakbd-cli) | `yakbd`, the command-line tool that converts and builds layouts |
| [`yakbd-gui`](https://github.com/yakbd/yakbd-gui) | the YAKBD Editor, a desktop editor for Windows, macOS and Linux |
| [`kbl-spec`](https://github.com/yakbd/kbl-spec) | the `.kbl.json` format, its JSON Schema and checker |
| [`yakbd.github.io`](https://github.com/yakbd/yakbd.github.io) | the website |

A preview, MIT-0. [Contributing](https://yakbd.github.io/contributing).
